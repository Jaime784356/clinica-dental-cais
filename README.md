# Clínica Dental Cais · Web

Landing de captación para Clínica Dental Cais (Rivas-Vaciamadrid).

- `index.html` — página principal
- `assets/styles.css` — estilos
- `assets/main.js` — reserva online, calculadora de financiación y ajustes

## Ajustes rápidos (`assets/main.js`, objeto `CONFIG`)

- `horario` — días y tramos de apertura (se usan en la reserva online y en el texto de horario)
- `festivos` — días sin citas
- `ocupadas` — horas ya ocupadas por día
- `plazasLibres` — plazas de primera visita gratis que quedan este mes
- `formEndpoint` — dirección a la que se envían las reservas (p. ej. Formspree)
